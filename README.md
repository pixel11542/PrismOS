# PrismOS
A OS For my DIY Phone.

  PrismOS DIY Phone
  You are able to modify this firmware.

  Software requirements: 
  
    SPI.h
    Wire.h
    esp_task_wdt.h
    Arduino_GFX_Library.h
    WifiClientSecure.h
    SD.h
    Preferences.h

    JPEGDecoder.h
    PNGdec.h


    "image_data.h"

  
  Hardware requirements:
  
    320xRGBx480 (pixels)
    Driver IC	ST7796S
    Display Interface	4-Line SPI
    Touch Screen Type	Capacitive Touch Screen
    Touch Screen Resolution	320x480(pixels)
    Driver IC	FT6336U
    Communication Interface	IIC
